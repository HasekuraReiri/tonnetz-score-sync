# 曲谱同步 · Tonnetz

把 **MusicXML / MXL 总谱**放进浏览器，左边显示 Verovio 原生排版的总谱并连续横向流动，右边用 **Tonnetz 和弦网络**同步展示当前调性、和弦与功能。纯前端、无构建步骤、离线运行。

仓库只保留运行所需的核心文件：页面、脚本、示例总谱与谱面图块；不含测试、录屏、导出、缓存等过程文件。

## 功能

- **原生总谱同步**：14 声部总谱、固定 35% 蓝色阅读线、连续横向流动；符头、连线、力度、演奏法都来自 Verovio 排版。
- **和声分析**：按调号、低音、强拍与旋律权重推断调性；给出罗马数字、T/S/D 功能、和弦记号与组成音。支持 **自动 / 调性 / 无调性** 三种模式，无调性时自动改为 0–11 音集。
- **Tonnetz 和弦网络**：横向纯五度、右上大三度、右下小三度；当前和弦只填充三角形，不标顶点。网格锚定全曲主调，默认不随换和弦移动；只有当前和弦多边形将要越出网格时，才沿越界方向做最小平移，并保留 10px 边距（位移小于 2px 忽略），保证和弦始终完整可见。网格右上在局部离调时显示「锚定 X 调」。
- **和弦进行行**：前两个、当前、后两个共 5 格，含罗马数字、功能、组成音、小节与时长。
- **音级圈**：五度圈 / 十二平均律圈，可单独或同时显示。
- **四部和声**：默认关闭，可勾选显示 S/A/T/B 与声部连接。
- **现场视频同步**：上传演奏视频，自动检测第一个有效声音、裁掉开头准备时间；视频音轨成为主时钟（乐谱合成自动静音），谱面按对齐表跟随演奏；画面进入右下视频区，播放中不出现绿幕。
- **分辨率**：默认 1920×1080，可选 2560×1440 / 3840×2160；支持截图与实时录制 MP4。

## 快速开始

Windows：

1. 双击 **`启动.cmd`**（或 `launch.cmd`）。
2. 启动器会在 `8850–8870` 找空闲端口并打开浏览器。
3. 停止用 **`停止.cmd`**。

其他系统（任意静态服务器）：

```bash
python3 -m http.server 8850
# 打开 http://127.0.0.1:8850/
```

> 不要直接双击 `index.html`：页面使用 ES Module，必须通过 HTTP 访问。

打开后自动载入内置示例总谱 `samples/sync (7).mxl`（勃拉姆斯第一交响曲第一乐章）。

## 操作

| 操作 | 说明 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← / → | 前后 5 秒 |
| 拖动进度条 | 立即跳转 |
| 分析模式 | 自动 / 调性 / 无调性 |
| 级数版本 0–11 | 网格与音级圈改用数字音名 |
| 四部和声 | 显示 / 隐藏 SATB |
| 五度圈 / 12 平均律圈 | 显示对应音级圈 |
| 上传视频 | 选择本地视频，自动裁头对齐；视频音轨接管播放 |
| 分辨率 | 1920×1080 / 2560×1440 / 3840×2160 |
| 导出视频 | 30 / 60 / 120 秒或全曲，实时录制 |

## 现场演奏同步

上传视频后：

1. 解码音轨，检测第一个持续有效声音，裁掉开头准备时间；
2. 视频成为主时钟，页面不再启动乐谱合成，直接播放视频音轨；
3. 谱面时间由视频时间换算：默认线性（`videoTime - lead`）；也支持通过 `stage.setVideoWarp()` 传入对齐表（`score` / `video` 两组时间点，线性插值），用于跟随有 Rubato 的真实演奏；
4. 播放、暂停、拖动进度条都会同步到视频；视频画面进入右下视频区，播放时不会露出绿幕。

仓库不附带演奏视频与对齐表；对齐表可由外部工具生成后通过 `stage.setVideoWarp()` 使用。

## 内置示例与限制
- 仓库只附带 **一首示例总谱的谱面图块**（勃拉姆斯第一交响曲第一乐章，513 小节，14 声部）。
- 载入其他 MXL 时，播放、和声分析与 Tonnetz 仍然工作，但谱面位置会显示「该总谱的谱面图块尚未预渲染」——这是为了避免把示例谱面错配到其他作品。
- 谱面是 `score-data/sync7/tiles/` 里的 53 张 3350×1770 预渲染图块，不是运行时 Verovio；缩放窗口不会重排。
- 四部和声是由和弦音集生成的演示性 SATB，不是原谱各声部的真实分配。
- 和声/调性为启发式分析，现代音集可能显示为 `[0,2,7]` 这类音集。
- 反复记号不展开，按谱面书写顺序播放。
- 未上传视频时音频为浏览器实时合成；上传视频后使用视频自带音轨。

## 关于谱面图块

图块由 Verovio 原生 SVG 预先排版、压缩谱表间距后栅格化得到，运行时不依赖 Verovio。重新生成需要本机 Verovio 与无头浏览器，属于构建流程，不在本仓库内。
